# Repository-layer pilot research

Per-service git-history reviews of Drizzle repository / data-access files.
Used to derive **feature-agnostic** skills for writing repository-layer code.

Each service folder is produced by a dedicated subagent:
- `00-summary.md` — themes and skill-candidate patterns
- `issues/*.md` — one file per concrete before→after finding

Pilots: logs, forms, users, files, languages.
